<Update label="November 8, 2026" description="Empty Squid reads its type from the body, unknown paths answer 404, Google Maps URLs without a map position, up to about 330 places per Google Maps search">

## Fixed

**Empty Squid: `type` sent in the body is read**

`POST /v1/squids/{squid_hash}/empty` read `type` from the query string only, while this documentation sends it in the body. A body `{"type": "url"}` was ignored and every task of the squid was removed. `type` is now read from the body, then from the query string; without it, every task is removed, as before. `deleted_count` is now the number of tasks removed: it also counted each task's run records. See [Empty Squid](/docs/empty-squid).

**Unknown paths answer 404 whatever the method**

A POST, PUT, PATCH or DELETE on a path that does not exist answered 405 `MethodNotAllowed`, as if the route existed with another method. It now answers 404 `HTTPNotFound`, like a GET. Tasks are added with `POST /v1/tasks` and runs started with `POST /v1/runs`.

**Google Maps Leads Scraper: search URLs without a map position**

A search URL without `@lat,lng` (`google.com/maps/search/plumber+Moreton+Bay+QLD+Australia`) names no search point. Geo Match, on by default, measured places from the map's default view instead and dropped them all, so these runs returned 0. Geo Match no longer applies to such URLs, and the run log says so: "No map position in this URL: Geo Match skipped."

**A place set aside after enrichment is not enriched again in the same run**

With a filter applied after enrichment (Google Maps Skip without email, Without website or Without phone; PAP and Pinterest filters of the same kind), a place set aside came back each time a neighbouring search returned it, and paid Business Details and email extraction again. It was never billed, but it slowed the run down: on a sweep of neighbouring zip codes, 12,305 of 15,149 enrichments were repeats. A run now remembers the places it set aside, and the run log says `Skipped '<name>' — Already filtered out.`

## Improved

**Google Maps Leads Scraper: up to about 330 places per search**

Google serves a dense search over two pages of results; the scraper stopped after the first 200. It now reads the second page too: up to about 330 places where the map is dense (278 for restaurants in central Paris, 257 for gyms in Manhattan), fewer elsewhere. The second page is only read when Max Results Per Task is empty or above 200. `max_results` now accepts up to 500.

**Every run processes every task of the squid**

The documentation now says it, and how to run only new inputs: a new squid, or remove the done tasks first. [Delete Task](/docs/delete-task) and [Empty Squid](/docs/empty-squid) remove tasks only: the results of earlier runs stay downloadable, by run and by squid. See [Add Tasks](/docs/add-tasks).
