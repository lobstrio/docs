Configure the scraper parameters to control how Google News articles are collected. These settings include language, recency filters, result limits, and topic-based scraping.

## Headers

<ParamField header="Authorization" type="string" required>
  Your API authentication token. Value: `Token YOUR_API_KEY`
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Request body format. Value: `application/json`
</ParamField>

## Scraper Parameters

Set these parameters in the `params` object:

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| **language** | string | — | Country edition and UI language for Google News (e.g., `English (United States)`) |
| **time_range** | string | — | Filter by recency: `Any time`, `Past hour`, `Past 24h`, `Past week`, `Past year`. The tighter of `time_range` and `fetch_since` wins. |
| **max_results** | integer | 100 | Maximum articles to scrape per task. For keyword tasks requesting more than 100, the scraper walks backwards day by day from today (~100 articles per day). For topic tasks, limited to what the topic page returns (~100–200 articles). |
| **topic_url** | string | — | Scrape a Google News topic instead of task keywords. Accepts a predefined topic name (`WORLD`, `NATION`, `BUSINESS`, `TECHNOLOGY`, `ENTERTAINMENT`, `SPORTS`, `SCIENCE`, `HEALTH`) or a topic/section URL from news.google.com (`https://news.google.com/topics/{id}` or `.../sections/{sid}`). When set, task keywords are ignored — a single task is enough. |
| **fetch_since** | string | — | Stop collecting articles older than this threshold. Use a relative duration (`24h`, `7d`, `2w`) or an absolute date (`YYYY-MM-DD HH:MM:SS`). Combines with `time_range` — the tighter constraint wins. |
| **fetch_since_timezone** | string | — | Timezone for interpreting an absolute `fetch_since` date (e.g. `Europe/Paris`). Ignored for relative values. |

<Tip>
  Use `topic_url: TECHNOLOGY` to monitor a full Google News topic section without managing individual keyword tasks.
</Tip>

<Tip>
  Use `fetch_since: 7d` combined with `time_range: Past week` to ensure you only collect recent articles.
</Tip>

## Code Examples

<CodeGroup>
```bash cURL
curl -X POST "https://api.lobstr.io/v1/squids/YOUR_SQUID_HASH" \
  -H "Authorization: Token YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Google News Search Export",
    "concurrency": 1,
    "export_unique_results": true,
    "to_complete": false,
    "no_line_breaks": true,
    "params": {
      "language": "English (United States)",
      "time_range": "Past week",
      "max_results": 100,
      "fetch_since": "7d"
    }
  }'
```

```python Python
import requests

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.lobstr.io/v1"
headers = {"Authorization": f"Token {API_KEY}"}

squid_id = "YOUR_SQUID_HASH"

# Update scraper settings
response = requests.post(f"{BASE_URL}/squids/{squid_id}",
    headers=headers,
    json={
        "name": "Google News Search Export",
        "concurrency": 1,
        "export_unique_results": True,
        "to_complete": False,
        "no_line_breaks": True,
        "params": {
            "language": "English (United States)",
            "time_range": "Past week",
            "max_results": 100,
            "fetch_since": "7d"
        }
    }
)

data = response.json()
print(f"Updated: {data['name']}")
print(f"Time range: {data['params']['time_range']}")
print(f"Max results: {data['params']['max_results']}")
```
</CodeGroup>
