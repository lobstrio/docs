---
title: "Get Results"
description: "Retrieve scraped data from Similarweb Scraper"
api: "GET https://api.lobstr.io/v1/results"
---

Retrieve scraped data from your **Similarweb Scraper** runs. One row per website. Add-on fields are only populated when the matching add-on (`company_details`, `ai_traffic`, `competitor_details`) is enabled.

## Headers

<ParamField header="Authorization" type="string" required>
  Your API authentication token. Value: `Token YOUR_API_KEY`.
</ParamField>

## Query Parameters

<ParamField query="squid" type="string" required>
  Hash of the squid to get results from.
</ParamField>

<ParamField query="page" type="integer">
  Page number (default: 1).
</ParamField>

## Result Fields

### Export Websites

<ResponseField name="domain_name" type="string">
  Domain the row describes, as Similarweb indexes it. Example: `github.com`
</ResponseField>

<ResponseField name="source_url" type="string">
  Similarweb page this row was collected from.
</ResponseField>

<ResponseField name="scraped_at" type="datetime">
  UTC timestamp of the collection.
</ResponseField>

<ResponseField name="snapshot_date" type="datetime">

<ResponseField name="has_traffic_data" type="boolean">

## Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.lobstr.io/v1/results \
  -H "Authorization: Token YOUR_API_KEY" \
  -d "squid=YOUR_SQUID_HASH" \
  -d "page=1"
```

```python Python
import requests

response = requests.get(
    "https://api.lobstr.io/v1/results",
    headers={"Authorization": "Token YOUR_API_KEY"},
    params={"squid": "YOUR_SQUID_HASH", "page": 1},
)
print(response.json())
```
</CodeGroup>
