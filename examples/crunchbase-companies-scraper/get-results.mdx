---
title: "Get Results"
description: "Retrieve scraped data from Crunchbase Companies Scraper"
api: "GET https://api.lobstr.io/v1/results"
---

Retrieve scraped data from your **Crunchbase Companies Scraper** runs. One row per company. Company-URL tasks return every field for free on the first request; search tasks return the core fields for free and the "Full Company Details" fields only when `company_details` is enabled.

<Note>
  Crunchbase gates funding dates and amounts behind its paid plan, so `last_funding_amount`, `last_funding_currency` and `last_funding_date` are only filled for the minority of companies (about 3 of 20 sampled) where Crunchbase still publishes the amount on the public activity timeline.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  Your API authentication token. Value: `Token YOUR_API_KEY`.
</ParamField>

## Query Parameters

<ParamField query="squid" type="string" required>
  Hash of the squid to get results from.
</ParamField>

<ParamField query="page" type="integer">
  Page number (default: 1).
</ParamField>

## Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.lobstr.io/v1/results \
  -H "Authorization: Token YOUR_API_KEY" \
  -d "squid=YOUR_SQUID_HASH" \
  -d "page=1"
```

```python Python
import requests

response = requests.get(
    "https://api.lobstr.io/v1/results",
    headers={"Authorization": "Token YOUR_API_KEY"},
    params={"squid": "YOUR_SQUID_HASH", "page": 1},
)
print(response.json())
```
</CodeGroup>
