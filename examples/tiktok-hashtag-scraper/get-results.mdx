---
title: "Get Results"
description: "Retrieve scraped data from TikTok Hashtag Scraper"
api: "GET https://api.lobstr.io/v1/results"
---

Retrieve scraped data from your **TikTok Hashtag Scraper** runs.

## Headers

<ParamField header="Authorization" type="string" required>
  Your API authentication token. Value: `Token YOUR_API_KEY`.
</ParamField>

## Query Parameters

<ParamField query="squid" type="string" required>
  Hash of the squid to get results from.
</ParamField>

<ParamField query="page" type="integer">
  Page number (default: 1).
</ParamField>

## Result Fields

<ResponseField name="hashtag" type="string">
  The hashtag this video was collected from (without the leading #). Example: `lobstr`
</ResponseField>

<ResponseField name="hashtag_rank" type="integer">
  Position of this video in the hashtag's video feed at scrape time. Example: `1`
</ResponseField>

<ResponseField name="video_id" type="string">

## Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.lobstr.io/v1/results \
  -H "Authorization: Token YOUR_API_KEY" \
  -d "squid=YOUR_SQUID_HASH" \
  -d "page=1"
```

```python Python
import requests

response = requests.get(
    "https://api.lobstr.io/v1/results",
    headers={"Authorization": "Token YOUR_API_KEY"},
    params={"squid": "YOUR_SQUID_HASH", "page": 1},
)
print(response.json())
```
</CodeGroup>
